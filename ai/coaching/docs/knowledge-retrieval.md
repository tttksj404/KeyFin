# 일반 금융 질문의 공식 근거 검색

금융 개념 질문은 거래 연동 없이 답합니다. `knowledge/finance.json`의 공식 자료에 근거한 27개 카드를 검색한 뒤 GPU 모델이 질문에 필요한 근거를 최대 3개 선택합니다. 이는 카드 수이며 서로 다른 원문 출처 수가 아닙니다. 서비스가 선택된 설명과 출처를 조립하므로 모델이 금리·계좌 금액·URL을 임의로 작성하지 않습니다. **실시간 웹 검색이나 모든 금융 주제를 다루는 자유 생성 챗봇은 아닙니다.**

## 처리와 검증 경계

1. `knowledge_catalog.py`가 자료의 중복 ID, 출처 도메인, 날짜, 크기, 깨진 문자 여부를 검사합니다.
2. `knowledge_retrieval.py`는 주제어 일치와 승인 본문의 두 글자 조각(BM25) 점수를 함께 사용합니다. 주제가 명시되면 상위 8개를 고릅니다. 별칭은 없지만 본문과 겹침이 있으면, 유효 자료가 32개 이하인 소규모 목록은 전체를 GPU에 보여 의미로 선택하게 합니다. 한국어 바꿔 말하기가 글자 일치만으로 누락되는 문제를 줄이기 위한 제한된 방식이며, 더 큰 목록은 상위 8개를 유지합니다. 겹침 없는 미지원 질문과 만료 자료를 억지로 채우지 않습니다.
3. 자료 확인일 전이나 재검토 기한 이후의 자료는 추론 입력에서 제외합니다. 확인일은 개발 과정의 출처 점검일이며 독립 전문가 승인일을 의미하지 않습니다.
4. GPU가 고른 ID가 전체 목록에 있어도 **이번 질문에 전달한 자료에 없으면** 채택하지 않습니다. “복리와 고정금리를 각각”처럼 명시적으로 열거한 주제의 누락도 검사합니다. 이 검사는 명확한 열거만 다루며 임의 문장의 의미 완전성을 보증하지 않습니다.
5. 결과에는 출처 URL, 자료 버전·SHA-256, 확인일·재검토 기한·적용 범위가 저장됩니다. 이전 답변을 다시 읽을 때 현재 모델로 새로 생성하지 않습니다.

“그럼 그건 어떻게 계산해?” 같은 후속 질문은 직전의 명시적 사용자 주제를 참고합니다.
“복리 대신 리볼빙”처럼 바꾼 주제는 뒤의 대화에서도 제외한 주제를 다시 가져오지 않습니다.
문장 끝의 제외절 때문에 앞의 유효 질문까지 버리지 않는 회귀도 검사합니다.

GPU 입력에는 선택에 필요한 ID·제목·승인 본문을 넣고, URL·검토일·별칭 원문은
버전이 고정된 목록과 저장된 출처 정보에서 보존합니다. 실제 tokenizer가 전체 지시문·스키마·
이력을 합쳐 검사하며, 32개 이하라고 토큰 한도 통과를 가정하지 않습니다.

일반 개념과 오늘 금리·정확한 세후 계산을 함께 질문하면, 설명 가능한 승인 문단을
표시하되 `status=needs_source`를 유지할 수 있습니다. `missing`은 최신 자료·계약·과세·계산의
정해진 네 종류 중 최대 세 개만 받습니다. 개인 금액·현재 금리·수익액을 만들어 빈칸을 채우지 않습니다.

지원 주제는 복리, 예금·적금, 리볼빙, DSR, 고정·변동금리, 비상금, 분산투자, ETF, 신용점수에 더해 예산·필수/선택 지출·현금 흐름·순자산·대출 원리금·분할상환·부채상환 방식·중도상환·금리인하요구·채권·듀레이션·신용위험·유동성위험·펀드비용·순자산가치·실질금리·보험 자기부담금·면책입니다. 해외 기관 자료는 일반 개념의 근거이며 한국의 법률·세금·상품 약관으로 바꾸어 적용하지 않습니다.

## 자료 추가와 배포

기본 자료는 API 실행에 필요한 패키지 자산입니다. 테스트 입력이나 실험 결과가 아니므로 `src/coaching_service/knowledge/`에 둡니다. 자료를 추가할 때 공식 원문과 한국어 설명의 일치, 해당 국가·일자, 주제어와 검토 기한을 함께 확인합니다.

별도 배포 파일을 쓰려면 `COACHING_KNOWLEDGE_FILE`과 그 파일의 정확한 `COACHING_KNOWLEDGE_SHA256`을 함께 설정합니다. 해시가 다르면 시작에 실패합니다. 앱 사용자는 이 파일을 수정하는 API를 받지 않으며, 자료 변경 후 프로세스를 다시 시작해야 합니다. 읽기는 최대 512 KB, 최대 250개 자료로 제한합니다.

## 성능 수치의 의미

검색·선택·출처·질문 답변 검증은 금융 개념을 정확한 자료에 연결하는지의 검사입니다. 소비 예측 오차와는 다른 지표입니다. 새 합성 질문으로 지원 범위가 넓어진 것을 확인하더라도 전체 사용자 질문의 정답률로 일반화하지 않습니다. 최신 금리, 개인별 상품 추천, 등록되지 않은 법규·세금·복잡한 계산은 자료 보완이 필요합니다.

검증 코드는 `tests/test_knowledge_retrieval.py`, `tests/test_finance_questions.py`입니다. 실제 GPU 질문별 결과·지연·거절 상태는 R20 답변 검증에서 별도로 집계합니다.
