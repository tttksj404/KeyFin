# R21 통합 대화 후보의 반복 비교 불합격 기록

검증일: 2026-09-15  
상태: **불합격 — 운영 설정으로 승격하지 않음**

이 문서는 모델 호출을 줄이는 `combined_dialogue=true` 후보의 반복 비교 결과를 보존한다.
수치가 좋아 보이는 실행만 골라 채택하지 않기 위해, 가용성·응답 규격·독립 검토 상태를
성능 지연과 같은 통과 조건으로 적용했다.

## 비교 조건

기준은 `combined_dialogue=false`, 후보는 `combined_dialogue=true`이며, 배치 상한·모델
가중치·프롬프트 버전·질문·토큰 상한·동시 요청 조건은 동일하게 고정했다. 두 경로의 차이는
일반 금융 질문에서 경로 분류와 근거 선택을 한 번에 수행하는지뿐이다.

기준→후보, 후보→기준, 기준→후보 순서로 세 쌍을 실행했다. 각 실행은 알려진 32개 회귀
질문을 동시 요청 1·4·8에서 각각 한 번 처리해 96개 응답을 만든다. 따라서 96개를 독립적인
실사용자 문제로 해석하지 않는다.

각 실행은 다음 조건을 모두 만족해야 다음 실행을 시작하도록 봉인했다.

- 실제 서비스 성공, 시간 초과, 거절, 대체 응답을 분리해 기록한다.
- 스모크, 정리, 실행 전·후 보호 검사, 입력·소스·결과 증적 해시를 확인한다.
- 기존에 승인된 응답과 다른 projection은 독립 의미 검토 전까지 통과 수에 넣지 않는다.
- 한 실행이라도 실패하면 이후 실행과 후속 후보 실험을 중단한다.

## 결과

운영 관점에서는 6회 실행의 576개 요청이 모두 성공했고 시간 초과·거절·대체 응답은 없었다.
스모크 438/438, 정리·보호 검사·증적 검증도 6/6 통과했다. 그러나 응답 품질은 576개 중
573개만 기존 승인 projection과 일치했다.

마지막 후보 실행에서 하나의 일반 금융 교육 사례가 동시 요청 1·4·8에서 모두 새
`needs_source` projection을 만들었다. 이 세 응답은 형식상 정상이고 금융 수치나 FDT 결과를
바꾸지 않았지만, 사전에 승인된 projection 집합에 없고 독립 의미 검토도 끝나지 않았다.
따라서 내용이 틀렸다고 단정하지는 않되, 통과로 셀 근거도 없다.

| 항목 | 결과 | 판정에 미치는 의미 |
| --- | ---: | --- |
| 실제 서비스 성공 | 576 / 576 | 전송·실행 가용성만 확인 |
| 시간 초과·거절·대체 응답 | 0 / 0 / 0 | 품질 통과를 뜻하지 않음 |

## 결정과 다음 후보

`combined_dialogue` 기본값은 계속 `false`다. 이 결과를 근거로 호출을 한 번으로 합치거나
배치 설정을 바꾸지 않는다. 기존 실행·원문·해시는 사후 수정 없이 별도 증적 보관소에 봉인했다.

다음 후보는 통합 모델 답을 더 관대하게 허용하는 방식이 아니다. 명확한 단일 금융 개념 질문만
승인된 카탈로그 문장과 출처로 결정론적으로 응답하고, 개인 수치·계산·최신 정보·예측·복수 주제는
기존 경로로 돌려보내는 `deterministic_finance_fast_path`다. 이 후보는 이후 별도 동결 화면
검증에서 정의 범위 96/96 규격 통과와 모델 호출 0을 확인해 기본값으로 승격했다. 범위·지연
수치·제외한 주장은 [D1 빠른 경로 기록](deterministic-finance-fast-path-r21.md)에 분리했다.
`combined_dialogue`의 불합격 판정과 기본값 `false`는 이 변경으로 달라지지 않는다.

이 검증은 알려진 합성·회귀 질문에서의 응답 규격과 일관성에 관한 것이다. 실제 고객의 미래
잔액·소비 예측 정확도를 의미하지 않는다. 그 정확도는 예측 시점에 저장한 receipt를 이후 실제
거래·잔액으로 정산하는 별도 검증에서만 주장할 수 있다.
